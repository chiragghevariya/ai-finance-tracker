## 1. Portfolio Description (~200 words)

**AI-Powered Personal Finance Tracker — Delivered Project**

I designed and built a cross-platform personal finance app that turns raw spending
into clear, AI-driven insights. The client wanted users to understand their money
without manual data entry or spreadsheet headaches — so I combined a **Flutter**
mobile front-end with a **Laravel** REST API and **OpenAI's GPT-4o**.

What I delivered:

- **AI Finance Chat** — users ask natural-language questions like *"Where did I spend
  most last month?"* and get instant, context-aware answers built from their real
  transaction history.
- **Receipt Scanning** — snap a photo and GPT-4o Vision extracts the merchant, amount,
  date, and category, auto-filling the entry in seconds.
- **Smart Auto-Categorization** — expenses are categorized automatically as the user types.
- **Dashboards** with live pie charts, monthly budgets, and overspending alerts.

The Laravel API handles JWT authentication, transaction management, and all OpenAI
orchestration; the Flutter app delivers a clean, responsive UI with solid state management.

**Business impact:** by surfacing AI insights and budget warnings, users **reduced monthly
overspending by 40%**. The result is a polished, production-ready app that makes budgeting
effortless — and demonstrates real, working AI integration end to end.
